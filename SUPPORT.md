# SolidPilot support

SolidPilot is a working prototype and early-alpha open-source project. The fastest
way to get help or report a defect is through the public issue tracker:

<https://github.com/Bennyco86/q3ds-solidworks-mcp/issues>

## Before opening an issue

Check the README, current known limitations, and existing issues. Then include:

- your Windows and SOLIDWORKS release
- the SolidPilot commit or release you are using
- the MCP client and Python version
- the tool name and smallest request that reproduces the problem
- the complete structured response or relevant log excerpt
- whether the problem repeats in a new, simple document

If a model is required, reduce it to the smallest file that demonstrates the
failure and confirm that you are allowed to share it.

## Keep private data private

Do not put licence keys, access tokens, credentials, customer names, proprietary
models, confidential drawings, or private network details in a public issue.

Potential security vulnerabilities should follow [SECURITY.md](SECURITY.md)
instead of being disclosed publicly.

## Project scope

Support covers the SolidPilot bridge, documented setup, and reproducible tool
behaviour. It cannot provide a SOLIDWORKS licence, general SOLIDWORKS training,
or engineering approval for generated geometry. Always review CAD output before
manufacture or safety-critical use.

SolidPilot is independent and is not affiliated with, authorised by, or endorsed
by Dassault Systèmes or SOLIDWORKS.
